## Key Submission Requirements (CRITICAL)

### 1. ✅ Demonstration Video
- **Under 3 minutes**
- Show project working
- Judges NOT required to watch past 3-minute mark

### 2. ✅ Open Source Repository
- Must be **public repository**
- **OSI-approved open source license** clearly visible (MIT ✅)
- Code must be hosted and accessible

### 3. ✅ The `.kiro` Directory (CRITICAL)
- Must be at **root of project** (`/.kiro`)
- **NOT in `.gitignore`**
- This is how judges verify Kiro feature usage

### 4. ✅ Functionality
- Project must be **installable and run** as described
- Provide **clear instructions**
- Give judges access to test

## Judging Criteria (Equal Weight)

### 1. Potential Value (33%)
- How useful, unique, or scalable?
- Does it solve a real problem?
- Clear market need?
- **Intuitive UI that enhances functionality scores high**

### 2. Implementation (33%)
- **How well you used Kiro**
- Deep and strategic use of Kiro features
- Genuinely improved development workflow
- **More variety and depth = better score**

### 3. Quality and Design (33%)
- Creativity
- Originality
- Polish
- Delightful user experience
- Unique approach to solving problem
