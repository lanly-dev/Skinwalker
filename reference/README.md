# Reference — UI Design Assets

Drop images here during UI development. Any format works: `.png`, `.jpg`, `.svg`, `.webp`.

Everything in this folder is gitignored — images stay local and never end up in the public repo.

## Naming convention

```
dracula.png / dracula-*.png
frankenstein.png / frankenstein-*.png
skeleton.png / skeleton-*.png
```

## What goes here

- Rough sketches or mockups of the monster body layout
- Inspiration images (character art, vintage monster posters, Winamp skin screenshots)
- Color palette swatches
- SVG anatomy drafts before they move into `src/renderer/skins/`
- Screenshots of work-in-progress builds
